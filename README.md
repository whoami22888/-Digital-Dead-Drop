# 🧨 Digital Dead Drop

**Digital Dead Drop** is a location-based anonymous information system where messages are visible only when a user is physically present at the exact place where the message was dropped.

Inspired by the old spy concept of *dead drops*, this project brings the idea into the digital world using GPS-based proximity.

---

## 🚩 Problem Statement

People often share important local information in chats or social media, where it gets lost, ignored, or seen by the wrong audience.  
There is no simple way to leave **anonymous, location-specific information** that appears **only where it is relevant**.

---

## 💡 Solution

Digital Dead Drop allows users to:
- Drop anonymous digital notes at a physical location
- Lock visibility using a GPS radius
- Discover notes only when they physically enter that location

There are:
- **No profiles**
- **No chats**
- **No public feeds**

Only information, at the right place.

---

## 👥 User Roles

### 🔹 User (Anonymous)
- No login or identity required
- Can drop notes at a location
- Can view nearby notes only when within the radius

### 🔹 Admin
- Separate admin portal
- Can view all notes
- Can edit, delete, or assign notes to departments
- Can mark notes as resolved (removes them from user view)
